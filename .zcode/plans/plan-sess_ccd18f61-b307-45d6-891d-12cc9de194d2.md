# 自动锁定功能：空闲超时后自动锁定 Vault

## 概述
用户无操作超过设定时长后，自动调用已有的 `lock_vault` 后端命令（设 `dek = None`），前端切回解锁屏。配置存 localStorage，UI 在设置→安全。

## 实现（3 个文件）

### 1. `src/api.ts` — 新增 lockVault 包装

```ts
export async function lockVault(): Promise<void> {
  await invoke("lock_vault");
}
```

后端 `lock_vault` 命令已注册（main.rs:502），只需前端 wrapper。

### 2. `src/App.tsx` — 空闲检测 + 自动锁定

在 App 组件内（vault === "ready" 时激活）：

- 读取 localStorage `myshell-auto-lock-minutes`（默认 "30"，"0" = 禁用）
- 若 > 0：启动 `setTimeout(autoLockMs)`
- 全局事件监听（`mousemove` / `keydown` / `click` / `wheel` / `touchstart`，capture 阶段）重置定时器
- 节流：用 `lastActivity` 时间戳，每 5 秒内最多重置一次（避免 mousemove 高频触发）
- 定时器到期：调用 `lockVault()` → `setVault("checking")`（status effect 自动 re-query → 显示 unlock 屏）
- vault 不是 "ready" 时清除定时器（锁屏后不再计时）
- 设置变更时（监听 storage 事件或自定义事件）重新计算定时器

### 3. `src/components/SettingsPanel.tsx` — 安全设置新增选项

在现有 "安全" section（"修改登录密码" 之前）新增 "自动锁定" 子节：

- 标题：`🔒 自动锁定`
- 说明文字：`无操作超过指定时间后自动锁定，需重新输入密码`
- `<select>` 下拉：
  - 10 分钟
  - 30 分钟（默认）
  - 1 小时
  - 不启用
- 值存 localStorage `myshell-auto-lock-minutes`（"10" | "30" | "60" | "0"）
- 变更后 dispatch 一个 `window.dispatchEvent(new Event("myshell-auto-lock-changed"))` 通知 App.tsx 重算定时器

## 边界情况
- "不启用"（值 "0"）：首次解锁后不再自动锁定，直到重启 app
- 锁屏状态下不计时（vault !== "ready" 时 timer 清除）
- 设置面板打开时也算"活动"（设置面板内的交互会触发 click/mousemove）
- 多窗口：Tauri 单窗口，不存在多窗口同步问题

## 验证
- `npx tsc --noEmit`（纯前端改动，无需 cargo check）
- 实测：设为 10 分钟 → 不操作 → 10 分钟后应自动跳到解锁屏
