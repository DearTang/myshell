# AI 助手设置界面重设计方案

## 目标

1. 设置 → AI 助手改为**左右布局**：左侧供应商列表，右侧供应商详情（含多模型管理）
2. AI 实际窗口的模型选择改为**两步选择**：先选供应商 → 再选具体模型

## 数据模型变更（后端）

### 新增表 `ai_supplier_models`
```sql
CREATE TABLE IF NOT EXISTS ai_supplier_models (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    supplier_id INTEGER NOT NULL,
    model_id TEXT NOT NULL,
    label TEXT,             -- 可选显示名（如"GLM-4 Plus"），空则用 model_id
    sort_order INTEGER NOT NULL DEFAULT 0,
    FOREIGN KEY (supplier_id) REFERENCES ai_models(id) ON DELETE CASCADE
);
```
每个供应商（ai_models 行）拥有 N 个模型。`ai_models.model_id` 保留为"主模型"（向后兼容 + 默认值）。

### 新增列 `ai_settings.active_model_string`
```sql
ALTER TABLE ai_settings ADD COLUMN active_model_string TEXT;
```
记录当前选中的具体模型 ID（在 active_model_id 指向的供应商内）。

### 修改 `AiModelInfo` 结构体
增加 `models: Vec<SupplierModelInfo>` 字段，list_ai_models 时 JOIN 查出。

## 新增/修改后端命令

| 命令 | 说明 |
|------|------|
| `list_supplier_models(supplier_id)` | 列出某供应商的所有模型 |
| `add_supplier_model(supplier_id, model_id, label?)` | 添加模型 |
| `remove_supplier_model(id)` | 删除模型 |
| `save_ai_model` (修改) | 新增 `models` 参数，保存时同步模型列表 |
| `set_active_ai_model` (修改) | 新增 `model_string` 参数，同时记录 active_model_string |

### `load_settings` 修改
解析时若 `active_model_string` 非空，用它作为 API 调用的 model；否则回退到 `ai_models.model_id`。

### `src/hooks/useAiConfig.ts`
- 增加 reload 后 models 的同步

### `src/components/SettingsPanel.tsx` — AI 标签页重写
**左面板（~260px）：**
- 顶部"新建供应商"按钮
- 供应商列表（名称 + provider 徽章 + 使用中标记）
- 单击选中、双击编辑名称、右键/按钮删除

**右面板：**
- 未选中时提示"请选择或新建供应商"
- 选中后显示：
  - 基本信息：名称、provider 选择、Base URL、API Key、代理、Temperature
  - 预设选择器：可选预设（GLM/腾讯云等）自动填充，或"自定义"
  - 模型管理区域：
    - 已添加模型列表（可删除）
    - "从接口获取模型"按钮 → 调 `/models` → 成功则展示勾选添加；失败则提示手动添加
    - "手动添加模型"按钮 → 输入 model_id + label
  - 底部：保存 / 测试 / 设为默认

### `src/components/AiPanel.tsx` — 模型选择器改为两步
- 底部模型选择器改为级联：先选供应商 → 再选模型
- 显示格式：`供应商名 / 模型名`

## 实施顺序

1. **后端 DB 迁移**（db.rs）
2. **后端命令**（ai.rs + main.rs）
3. **前端 API 层**（api.ts）
4. **前端 Hook**（useAiConfig.ts）
5. **设置面板重写**（SettingsPanel.tsx AI 部分）
6. **AI 面板两步选择**（AiPanel.tsx）
7. **类型检查** `npx tsc --noEmit`
