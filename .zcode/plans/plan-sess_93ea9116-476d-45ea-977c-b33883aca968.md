# 多窗口展示功能实现方案

## 目标
在 CommandBar 的 AI 按钮左侧新增「🪟 多窗口」按钮。点击后弹出会话选择面板（复选框勾选已连接的 SSH 终端），确认后进入多窗口模式--所有选中会话以网格布局同时展示在终端区，每个窗口可独立操作。再次点击或点「退出多窗口」回到单标签模式。

## 核心设计：布局切换层（不重建终端）

多窗口是 App.tsx 终端堆叠区的一个**替代渲染模式**，不是新组件树：

- **单标签模式**（现有）：`tabs.map` -> 每个终端 `position:absolute; inset:0` 堆叠，`visibility` 控制可见。
- **多窗口模式**（新增）：选中会话的终端放入 CSS Grid 网格 cell，每个 cell 包裹同一个 TerminalPanel（key=tab.id 不变，React 复用实例，xterm 不重建）。

## 最小尺寸保护
- 每个网格 cell 设置 `minWidth: 320px`、`minHeight: 160px`
- 网格区允许 `overflow:auto`，放不下时出滚动条而非挤压

## 网格列数算法
- 2个 -> 1×2；3~4个 -> 2列；5~9个 -> 3列；≥10 -> 4列

## 新增文件
- `src/components/MultiWindowPicker.tsx`：会话选择面板（模态遮罩 + 复选框列表）

## 改动文件
- `src/components/CommandBar.tsx`：AI 按钮左侧插入「🪟 多窗口」按钮 + onOpenMultiWindow prop
- `src/components/TerminalPanel.tsx`：透传 onOpenMultiWindow prop 到 CommandBar
- `src/App.tsx`：新增多窗口状态 + 终端区渲染分支（单标签/网格）+ 工具条 + Picker 挂载

## 验证
- `npx tsc --noEmit` 通过
- dev 实测：连3个SSH会话 -> 点多窗口 -> 选3个 -> 2列网格展示 -> 每个可独立输入 -> 退出回到单标签 -> 终端历史保留
