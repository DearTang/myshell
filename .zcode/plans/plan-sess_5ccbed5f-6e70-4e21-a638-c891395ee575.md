为 Linux 添加"浏览器跳转"模式的更新支持(方案 A)。Windows 流程零改动。

## 设计思路
现有 UI 里**已经**有"浏览器下载"按钮(`UpdateNotification.tsx` failed phase、`AboutDialog.tsx` idle 的"网页下载" / failed 的"浏览器下载"),通过 `openExternalUrl` 打开 URL——而 `open_external_url` 在 Linux 上已经自动走 xdg-open(Tauri shell plugin 内置)。

所以最简做法是:**让 Linux 完全跳过下载/安装链路,直接走"打开浏览器"路径**。具体:
- 新增 `UpdateInfo.update_strategy: "auto" | "browser"` 字段。
- `check_for_updates` 在 Linux 上把 `update_strategy` 设为 `"browser"`、`download_url` 设为 `release_url`(release 页 URL)。
- 前端两个组件检测到 `update_strategy === "browser"` 时,**直接渲染"打开下载页"按钮**(替代原有的"更新"按钮),点击调 `openExternalUrl(release_url)`。
- `download_update` / `install_update` **完全不动**——Linux 路径根本不会调用它们。

Windows 分支完全不变:`update_strategy === "auto"` 走原流程。

## 代码改动

### 1. `src-tauri/src/main.rs` — Rust 后端
- `UpdateInfo` struct 末尾加一个字段:
  ```rust
  /// "auto" = 走内置下载+安装(Windows); "browser" = 跳浏览器让用户手动下载安装(Linux/macOS)。
  update_strategy: String,
  ```
- `update_info_error` helper 里给该字段填 `String::new()`(失败时该字段无意义)。
- `check_for_updates` 末尾构造 `UpdateInfo` 时:
  ```rust
  let update_strategy = if cfg!(target_os = "windows") {
      "auto".to_string()
  } else {
      "browser".to_string()
  };
  ```
  并在 Linux 分支把 `download_url` 设为 `release_url`(让 UI 的 `downloadUrl || release_url` fallback 直接拿到 release 页 URL)。Windows 分支保持原逻辑(取 assets[0])。

### 2. `src/api.ts` — TS 类型镜像
- `UpdateInfo` interface 加:
  ```ts
  /** "auto" 内置下载+安装(Windows); "browser" 跳浏览器(Linux/macOS)。 */
  update_strategy: string;
  ```

### 3. `src/components/UpdateNotification.tsx` — 更新通知弹窗
- 顶部判断 `const isBrowserMode = updateInfo.update_strategy === "browser";`
- `isBrowserMode === true` 时:
  - `phase` 初始直接设为 `"prompt"`,subtitle 文案改为"检测到新版本,请前往下载页手动下载安装(Linux 暂不支持自动更新)"
  - "更新"按钮替换为"打开下载页",点击调 `openExternalUrl(release_url)`
  - 不进入 `downloading` / `ready` phase
- Windows 路径(`isBrowserMode === false`)保持原逻辑不动。

### 4. `src/components/AboutDialog.tsx` — 关于对话框
- 同样 `const isBrowserMode = updateInfo?.update_strategy === "browser";`
- 在有更新(`hasUpdate`)的 banner 里:
  - `isBrowserMode === true` 时只显示"打开下载页"按钮(替代 idle phase 的"更新"+"网页下载"组合),副文案改"Linux 暂不支持自动更新,请前往下载页手动下载安装"
  - Windows 路径不变。
