## Vault 安全加固：删除 keyring 明文存储，强制走 GUI 解锁

### 安全目标
当前 MCP server 通过 keyring 拿 passphrase → 解锁 vault → 拿到所有连接明文密码 → 可绕过 GUI 访问任意服务器。改为：**MCP 完全不持有解密能力，所有服务器访问必须经过 GUI（用户已解锁 vault）**。

### 改动清单

#### 1. 新增纯文本连接查找（让 MCP 不再需要 DEK）
**文件**：`src-tauri/src/db.rs` + `src-tauri/src/lib.rs`
- 新增 `get_all_connections_plaintext(conn) -> Vec<ConnectionConfig>`：只查 `id, name, conn_type, group_path` 四个非加密列（host/username 等加密字段留空）
- 在 lib.rs 导出该函数

**文件**：`src-tauri/src/bin/myshell-mcp.rs`
- 新增 `find_connection_id(query, expected_type) -> Result<String>`：用纯文本查找，只返回 connection_id，**不调用 require_dek**
- `exec_in_gui_tab`（~1172 行）：把 `find_connection` 换成 `find_connection_id`
- sftp 相关工具（sftp_list/download/upload 等）如果也走 GUI 路径，同样改用 `find_connection_id`；如果它们当前是 headless（需要 resolve_secrets），则保留原样但会受 vault 状态约束

#### 2. 删除 keyring passphrase 存储链路
**文件**：`src-tauri/src/bin/myshell-mcp.rs`
- 删除启动时的 keyring 读取 + vault 解锁逻辑（~1400-1434 行的后台解锁线程）
- MCP 启动后 DEK 始终为 None，所有需要 DEK 的操作都会返回"请先打开 GUI 并解锁"

**文件**：`src-tauri/src/secrets.rs`
- 删除 `set_mcp_passphrase` / `get_mcp_passphrase` / `delete_mcp_passphrase`（~101-145 行）

**文件**：`src-tauri/src/main.rs`
- 删除 `mcp_save_passphrase` / `mcp_has_passphrase` / `mcp_delete_passphrase` 三个 Tauri command（~3542-3558 行）
- 从 `generate_handler!` 移除注册（~3872-3874 行）

**文件**：`src/api.ts`
- 删除 `mcpSavePassphrase` / `mcpHasPassphrase` / `mcpDeletePassphrase`（~1340-1353 行）

**文件**：`src/components/SettingsPanel.tsx`
- 删除 "🔐 Vault 密码同步" 整个 UI 卡片（~1898-2055 行）
- 删除相关 state（mcpPassphrase / mcpPassphraseStored / mcpSaving / mcpEditingPassphrase，~167-170 行）
- 删除初始化 useEffect 里的 keyring 检查（~197-204 行）
- 删除修改主密码时的 keyring 自动同步（~496-503 行）

**文件**：`src-tauri/src/bin/myshell-cli.rs`
- 删除 `VaultAction::SavePassphrase` 变体 + `cmd_save_passphrase` 函数（~126-132, 294-305, 316-332 行）

#### 3. 更新 MCP 错误提示
**文件**：`src-tauri/src/bin/myshell-mcp.rs`
- 当 GUI 未运行或 vault 未解锁时，MCP 工具返回清晰提示："请先打开 MyShell GUI 并输入主密码解锁保险库"
- MCP server instructions（system prompt 里的 ~203 行）更新：去掉"去 GUI 设置 MCP 支持同步密码"的指引，改为"请确保 GUI 已打开并已解锁"

#### 4. 验证点
- `cargo check --bin myshell-mcp` + `cargo check --bin myshell-cli` + `cargo check`（GUI）通过
- `npx tsc --noEmit` 通过
- MCP ssh_exec 在 GUI 已解锁时正常工作（走 show_in_gui tab 路径）
- MCP ssh_exec 在 GUI 未打开时报错提示打开 GUI

### 不改动
- 黑白名单 UI 改进（搜索/排序/字号）留作后续单独做，不混入这个安全改动
