# 连接高级选项：地址族（强制 IPv4/IPv6）+ 连接超时 + Keepalive 间隔

## 目标
为每个连接新增 3 个可选配置（用户已确认范围）：
1. **地址族** `address_family`：`auto`（默认）/ `ipv4` / `ipv6` — 解决 IPv6 黑洞导致连接卡顿
2. **连接超时** `connect_timeout_secs`：`Option<u32>`，None = 沿用 10s
3. **Keepalive 间隔** `keepalive_interval_secs`：`Option<u32>`，None = 沿用 15s

仅作用于 SSH/SFTP（SFTP 复用 SSH 会话自动覆盖）。

## 关键事实（已核实）
- `dial_and_authenticate`（ssh.rs:304）是唯一拨号咽喉，被 connect(459)、test_connection(430)、断线重连(993) 共用 → 改一处覆盖全部 SSH/SFTP 路径。
- 代理路径已用 `client::connect_stream`（ssh.rs:361）→ 强制地址族复用同模式（自己解析+拨号→connect_stream）。
- DB 有成熟幂等迁移（`column_exists` + `ALTER TABLE ADD COLUMN`）。
- CLI/MCP 无 `ConnectionConfig{}` 字面量，全经 db 读取 → 加 serde(default) 字段不破坏编译；main.rs:143 复制连接用 `..src` 展开自动继承。

## 改动清单

### 1. lib.rs（结构体）
`ConnectionConfig` 的 `terminal_font` 后追加：
- `address_family: String`，`#[serde(default = "default_address_family")]`（新 fn 返回 "auto"）
- `connect_timeout_secs: Option<u32>`，`#[serde(default)]`
- `keepalive_interval_secs: Option<u32>`，`#[serde(default)]`

### 2. api.ts（TS 镜像）
`ConnectionConfig` 接口追加 `address_family?: string`、`connect_timeout_secs?: number`、`keepalive_interval_secs?: number`。

### 3. db.rs（schema + CRUD 全落点）
新列：`address_family TEXT NOT NULL DEFAULT 'auto'`、`connect_timeout_secs INTEGER`、`keepalive_interval_secs INTEGER`。
- CREATE TABLE（24-46）追加 3 列
- 迁移（259 后）追加 3 个幂等 `column_exists`+ALTER 块
- save_connection INSERT（603-629）：列+`?21,?22,?23`+3 params
- get_all_connections / get_connection：SELECT 追加 3 列（索引 21/22/23）+ row map + 解构 + 结构体字面量（超时 `.and_then(|v| v.try_into().ok())` 转 Option<u32>）
- get_deleted_connections：新列保持索引 21/22/23，`deleted_at` 移到 24（更新原 get(21)→get(24)）
- get_all_connections_plaintext：结构体字面量补 3 个默认字段
- 实现时 `grep -rn "ConnectionConfig {" src-tauri/src` 复核无遗漏

### 4. ssh.rs（拨号核心）
导入 `std::net::SocketAddr`、`tokio::net::TcpStream`。
- (a) keepalive 每连接化：`keepalive_interval = Some(Duration::from_secs(config.keepalive_interval_secs.unwrap_or(15) as u64))`，max 保持 3
- (b) 超时每连接化：顶部算 `connect_timeout = Duration::from_secs(config.connect_timeout_secs.unwrap_or(10) as u64)`；`with_connect_timeout` 签名加 `timeout: Duration` 参数，两处调用传入
- (c) 地址族：新增 `dial_tcp(host, port, family, timeout)` —— `tokio::net::lookup_host` 解析 → 按 family 过滤（ipv4/ipv6/auto）→ 空则报"无可用 IPvX 地址" → `TcpStream::connect` 带 timeout。直连分支改为 `dial_tcp(...)` → `client::connect_stream`。代理分支不变。

### 5. ConnectionDialog.tsx（UI）
- 3 个 state hook（addressFamily / connectTimeout / keepaliveInterval，空串=默认）
- buildConfig 追加 3 字段（空串→undefined）；validate 校验数值 1-3600
- 代理 FieldGroup 后新增「高级选项」FieldGroup，仅 `connType === "ssh" || "sftp"` 显示：地址族 Select（自动/强制IPv4/强制IPv6）+ 两列 Input（连接超时、Keepalive 间隔，留空=默认）
