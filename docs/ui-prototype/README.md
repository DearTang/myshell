# MyShell 统一应用主界面原型

这是一个不依赖构建工具、可直接作为其他桌面/管理软件界面架构参考的高保真 HTML 原型。

## 查看方式

直接双击 `index.html`，或在本目录启动任意静态文件服务：

```bash
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/index.html`。

## 已实现交互

- 左侧菜单展开 / 收缩；收缩时悬浮或键盘聚焦图标可显示菜单名称；窄屏下自动切换为抽屉菜单
- 左下反馈入口、版本号、升级绿点与箭头；点击版本号打开版本更新弹窗
- 顶部全局栏：应用品牌、搜索、通知、亮暗主题、国际化、设置、用户入口
- 中文 / 英文即时切换
- 深色 / 浅色 / 跟随系统主题
- 设置抽屉：紧凑模式、右侧辅助区、架构标注、品牌强调色
- `Ctrl + K` 打开全局命令面板
- 会话类型筛选、快速终端输入、Toast 操作反馈
- 1440、920、680 三档响应式布局
- `prefers-reduced-motion` 无障碍动效降级

## 统一架构区域

1. **Global Topbar**：应用级品牌、搜索、通知和全局设置。
2. **Navigation Rail**：业务模块导航、资源提示和版本入口。
3. **Primary Workspace**：页面标题、全局状态信号轨和核心功能面板。
4. **Utility Rail**：健康状态、活动历史和智能助手等辅助信息。
5. **Overlay Layer**：设置抽屉、命令面板、更新弹窗和 Toast。

点击页面右上方的“架构标注”可以直观看到四个主要区域。

## 复用到其他软件

- 在 `index.html` 替换应用名、菜单与功能卡片内容。
- 在 `styles.css` 顶部修改 `--accent`、背景令牌、字体和区域宽度。
- 保留五区信息架构与 Overlay 层；按照业务需要增删 Primary Workspace 中的面板。
- 实际项目中可将 Button、Panel、Status、Drawer、Dialog、Toast 等拆为基础组件，页面区域拆为 Shell/Panel 组件。

## 文件说明

- `index.html`：语义化页面结构与真实演示数据
- `styles.css`：设计令牌、组件样式、主题和响应式规则
- `app.js`：主题、国际化、侧栏、设置、弹窗和演示交互
