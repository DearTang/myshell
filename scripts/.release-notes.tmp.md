## v1.5.0（2026-06-24）

版本信息展示 + 自动检测更新体系首版。

#### ✨ 新增
- **版本号展示**：侧边栏底部常驻显示当前版本号（如 `v1.5.0`），点击打开关于对话框；发现新版本时版本号旁出现青色提示红点
- **自动检测更新**：启动后台静默检测 Gitee 最新 release（每 24h 节流一次，避免频繁请求）；发现新版本首次弹出「发现新版本 vX.X.X」提示并提供「去下载」（同一新版本只提示一次，后续仅留红点，不打扰）；关于对话框内可手动「检查更新」并「去下载」跳转浏览器。检测走 Rust 后端 `reqwest`，不受前端 CSP 限制
- **更新内容展示**：版本升级后首次启动自动弹出更新日志（CHANGELOG）；首次安装静默不弹（不打扰新用户）；更新日志内置打包（Vite `?raw`），离线可用、与已装版本严格对应
- **连接测试按钮**：新建/编辑连接对话框新增「测试」按钮，保存前即可验证 SSH/SFTP/FTP/本地终端能否连通；测试与真实连接共用同一条拨号+认证+主机键 TOFU 路径
- **AI 配置测试按钮**：设置 → AI 助手，「保存 AI 配置」旁新增「测试」按钮，用当前表单值发起最小请求验证，无需先保存
- **AI 助手输入框加高**：主页 AI 助手输入框由 2 行加高到 4 行
- **连接拖拽移动**：长按连接（600ms）拖到文件夹即移动归类；拖拽激活时列表只展示文件夹
- **启动白屏消除**：主窗口启动先隐藏，前端首帧绘制完成后再显示

#### 🛠️ 优化
- **新建连接字体字段移到底部**：常用字段（名称/主机/端口/认证）优先露出，字体外观项靠后
- **一键发布流水线**：新增 `打包` 触发的自动发版流程 + `scripts/publish-gitee-release.mjs`

#### 🔒 安全
- 更新检测 HTTP 放 Rust 后端，**无需放宽 CSP**；打开外链命令强制校验 `http(s)://` 前缀；检测失败一律降级为「无更新」，绝不抛错到前端
